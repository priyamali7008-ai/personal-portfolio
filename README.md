# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, projects, education, and professional profile through a clean, responsive, and user-friendly website.

## 👩‍💻 About the Project

This portfolio website is designed to provide an overview of my background, technical skills, projects, and contact information.

The website is built using modern web development technologies with a focus on:

* Responsive design
* Clean and simple user interface
* Semantic HTML5 structure
* Accessibility
* Easy navigation
* Professional presentation

## ✨ Features

* 🏠 **Home Page** – Introduction and personal profile
* 👩‍💻 **About Page** – Information about my education, skills, and background
* 💼 **Services Page** – Overview of the services and technical areas I can work with
* 📁 **Portfolio Page** – Showcase of my projects and work
* 📞 **Contact Page** – Contact information and social media links
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices
* ♿ **Accessibility** – Uses semantic HTML and accessibility-friendly elements
* 🎨 **Modern UI** – Clean layout, typography, images, and hover effects

## 🛠️ Technologies Used

* **HTML5** – Website structure and semantic elements
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript** – Interactive functionality
* **Font Awesome** – Icons
* **Google Fonts** – Typography

## 📱 Responsive Design

The website is designed to provide a consistent experience on different screen sizes, including:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

CSS media queries are used to adapt the layout for smaller screens.

## ♿ Accessibility

Accessibility has been considered throughout the website by using:

* Semantic HTML5 elements
* Alternative text for images
* Descriptive navigation links
* Proper heading hierarchy
* ARIA labels where appropriate
* Keyboard-friendly navigation
* Sufficiently clear visual presentation

## 🎯 Project Goals

The main goals of this project are to:

1. Create a professional online presence.
2. Showcase my technical skills and projects.
3. Practice modern HTML and CSS development.
4. Build a responsive multi-page website.
5. Demonstrate basic web accessibility principles.
